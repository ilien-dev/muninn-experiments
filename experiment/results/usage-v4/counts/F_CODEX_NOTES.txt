Which state of f_codex.py produced each f_codex_*.json

f_codex.py fires the commands a project's .codex/hooks.json registers. Two things about it
changed after its first commit (ba271c1e), both in 86d746c4: its import of `common` was fixed
(as first committed it could not start), and on Windows it fires through PowerShell, where it
first fired through cmd.exe. The state between the two, with the import fixed and cmd.exe
still the shell, was never committed. It differs from 86d746c4 by one call:
    C.run('cmd.exe /S /C "%s"' % line, ...)
where the committed script has
    C.run(['powershell.exe', '-NoProfile', '-Command', line], ...)
